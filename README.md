# 🚀 Arman Husain - Developer Portfolio


A modern, animated developer portfolio built using **Next.js 13 App Router**, **Tailwind CSS**, and **Framer Motion**.  
Showcases your skills, projects, experience, and verified certificates with sleek visuals and smooth interactions.

---

## 🔧 Tech Stack

| Technology      | Description                                      |
|------------------|--------------------------------------------------|
| **Next.js 13**   | App Router for optimized routing & SSR support  |
| **Tailwind CSS** | Utility-first styling framework                 |
| **Framer Motion**| Animation for scroll, hover, and load effects   |
| **TypeScript**   | Type-safe development experience                |
| **React**        | Frontend library for building UI components     |

## 🧠 Features

- 🌌 Full-screen video or canvas background
- 🧠 Scroll animations with `framer-motion`
- 💼 Experience and Certificate cards with 3D tilt
- 💬 Contact modal via `mailto:`
- 💻 Fully responsive across all screen sizes
- 🎉 Subtle hover/entry animations for engaging UX

## 🚀 Running Locally

```bash
# Clone the repo
git clone https://github.com/Arman-Husain/portfolio.git

# Enter the project directory
cd portfolio

# Install dependencies

# Run the development server
npm run dev
